# 保存任务检查点

让下一会话知道从哪里继续、哪些判断仍未确定、哪些动作不能贸然重复。保存这些恢复信息即可，不以填满栏目或留下完整过程为目标。

## 先判断需要留下什么

读取适用规则、已有 State、当前 Plan 的目标与相关安排，再核对相关 worktree、Git diff 和实际证据。文字、图表或 Wiki 都可作为资料入口，只追查影响恢复的部分；不复制整个项目地图或把链接当作全文必读清单。

对每条候选内容问：**下一会话少了它，会做错什么、重复什么，或付出明显的重建成本吗？** 代码、测试、Git 或现有材料已足够表达的内容，只需给出必要定位，甚至可以不写。

- 同一逻辑任务沿用同一份 State，优先使用现有路径；无约定时可用 `docs/work/active/<task>/STATE.md`。会话、日期和阶段变化不产生第二份交接文档。
- 简单任务可以没有 State；用户明确要求保存时，几句话也可以。没有 Plan 不必为了检查点补建 Plan。
- 任务已经完成时如实报告，不编造下一步来维持 active 状态，也不因此自动整理整个文档库。

## 重写当前快照

State 的内容和结构随现场选择，不设必填章节。通常有用的是：

- **从哪里继续**：当前落点、下一项具体动作；目标或验收范围链接到当前 Plan 或既有任务入口。
- **必要现场**：正确仓库/worktree、分支与 HEAD，以及影响接手的未提交改动、用户改动归属或文件位置。多仓任务分别定位，不能用一个 SHA 代表全部现场。
- **影响下一步的未决事项**：阻塞、待确认判断、未完成验收，以及会使人重走弯路的已排除路线。说明已知事实与推测的区别。
- **仍影响选择的理由**：用户为何选定或否决某方案、适用条件是什么。已有 Plan 或决策说明承载时只引用；尚未落地且难以重建的理由保留一句，避免接手者重复提案。
- **必须保留的中间状态**：请求是否已发出、结果是否未知、迁移是否部分执行，以及据此不能重复的动作；保留核查入口，避免下一会话误重试。

只保留仍影响当前工作的完成结论。过往阶段成绩、所有测试结果、候选经验、调查过程和未来点子不作为常驻栏目积累。保留下来的证据摘要应能识别结果、适用提交或环境及必要时间信息；未在本次重验就按原证据表述，不冒充新验证。不要为写检查点重复付费调用、发布或高成本测试。

可选示例见 `./templates/task-state.md`；无需读取或照抄模板即可完成检查点。

涉及图表或其他产物时，必要定位包括主要维护位置、可编辑源与展示版本，以及已知的更新缺口。旧图尚未重建时保留其失效范围，不能把旧视图作为当前事实；保存检查点不要求顺带重画全部资料。形式取舍不明确时可参考 `./references/project-materials.md`。

## 把方案变化整合回方案

已决定且在授权范围内的执行变化，直接修订当前 Plan 的相关段落，使它表达当前有效方案；不要让读者用原文叠加 State 中的补丁才能知道接下来做什么。

- 完整剩余范围与验收条件只在当前 Plan 或既有待办入口维护，State 保留当前卡点和短下一步。没有独立入口的小任务可直接在短 State 中说明剩余工作。
- 调整路线不能静默缩减目标或验收条件。尚需用户裁决的范围变化保留为待决问题，不当作已批准计划。
- 同一任务通常就地修订 Plan；实质重定任务范围、确需保留独立基线或用户要求保留原稿时，才新建替代 Plan，明确旧稿已被替代及双向链接，保持唯一当前入口。
- 独立且未承诺实施的后续事项，确有保留价值时进入既有 Issue/Backlog；不能把当前必做项转移进去后宣布完成。

## 压缩时保住真正的证据

先确认被移除的信息是否已有可靠落点。Git 只有在内容确已提交、可定位且可恢复时才能承担历史；未提交调查、唯一运行产物和用户提供的原始证据不能因为“Git 会保存历史”而丢弃。

难以重建、确有后续用途的证据可保留在现有产物或按需创建的专题材料中，State 仅留用途和定位。不为缩短 State 新建一个无限追加的附录或 Report，也不把所有移出内容机械搬进 Knowledge/Backlog。没有未来决策价值且不是唯一必要证据的过程内容可以直接去掉。

保存检查点不授权清理调试产物、覆盖用户改动、扩大任务或执行外部操作。敏感内容只留安全定位，不复制密钥、Cookie 或原始用户数据。

## 确认能接手

回读 State，核对关键定位和链接。确认下一会话能识别完整任务入口、关键理由、第一项动作、当前阻塞及不可重复的动作，且不需要默认阅读全部历史。新快照取代旧内容，不追加本轮会话日志；没有影响接续的新事实时保留已有表达。

向用户简短说明保存位置、仍未确定的事项和下一步；没有需要额外保存的信息时说明即可，不生成形式性文件。
