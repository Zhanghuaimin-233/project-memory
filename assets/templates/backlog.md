# <项目名> Backlog

本文件只保存已经发现、尚未承诺立即实施、又值得避免遗忘的独立后续工作。项目已有 Issue 系统时，优先使用 Issue，不再维护本文件。

## 使用规则

- 影响当前任务验收的事项留在当前 State，不得移入 Backlog 后宣布任务完成。
- 已确定近期实施的事项进入 Plan；真正开始执行后进入对应 State。
- Report 保存问题证据，Backlog 只保存未来是否处理以及做到什么算完成。
- 只保留未完成事项。完成、放弃或被替代的条目直接删除，由 Git 保存历史。
- 不为单个小问题创建独立 Markdown，不把 Backlog 扩写成多份小型计划书。
